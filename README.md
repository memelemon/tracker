# Дневник работы

Личный рабочий дневник meme_lemon.

Основной сайт: https://memelemon.space/

## Записи
Отчёты выводятся в хронологической ленте, в исходной формулировке, без пересказа и редактирования. Поиск фильтрует записи по тексту. Записи хранятся в `data.json` внутри соответствующих месяцев и лет.

## Задачи
На каждый месяц задаётся отдельный список задач. Отметки о выполнении сохраняются локально в браузере посетителя и не меняют общий файл данных.

## Учёт
ChatGPT оценивает значимость работы, алгоритм ведёт структуру данных и рассчитывает показатели. Отсутствие записи не доказывает отсутствие работы.
