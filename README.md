# ДНЕВНИК РАБОТЫ

Это личный дневник meme_lemon о проделанной работе. Если вы посетитель, вы можете просматривать записи. Сайт показывает внутреннюю отчётность meme_lemon по собственным проектам.

## Структура
- Календарь месяца — даты отчётов и периоды, которые они охватывают.
- Недели — недельные показатели и их вклад в общий цвет месяца.
- Категории — сводка активности по направлениям.
- Отчёты — архив записей о завершённой работе.

## Данные
- `index.html` — страница дневника.
- `data.json` — месяцы, категории, недельные показатели и записи отчётов.

## Принцип учёта
- Среднее значение месяца рассчитывается по четырём недельным показателям.
- Неделя без записи учитывается как 0 только в показателе зарегистрированной активности. Это не означает, что работа не велась.
- Знак «—» означает отсутствие данных, а не нулевой результат.
- Если отчёт охватывает несколько дней, календарь показывает этот период цветовым градиентом. Это не распределение работы по конкретным дням.
