# Дневник работы

Личный рабочий дневник meme_lemon.

Основной сайт: https://memelemon.space/

## Публичная страница
- Краткая сводка о последнем месяце.
- Календарь с отмеченным периодом отчёта и датами публикаций.
- Лента исходных записей без пересказа и редактирования.
- Поиск по тексту записей.

Планирование задач ведётся отдельно и не публикуется на сайте.
