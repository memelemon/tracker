# ДНЕВНИК РАБОТЫ

Это личный дневник meme_lemon о проделанной работе. Отчётность составляет сам meme_lemon: он описывает результаты и определяет, что следует учитывать. Алгоритм организует записи, распределяет их по структуре дневника, рассчитывает сводные показатели и отображает динамику цветом. Посетители могут свободно просматривать записи. Это внутренняя отчётность meme_lemon по собственным проектам.

## Структура
- Календарь месяца — даты отчётов и периоды, которые они охватывают.
- Недели — недельные показатели и их вклад в общий цвет месяца.
- Категории — сводка активности по направлениям.
- Отчёты — архив записей о завершённой работе.

## Данные
- `index.html` — страница дневника и алгоритм отображения.
- `data.json` — месяцы, категории, недельные показатели и записи отчётов.

## Принцип обработки
- meme_lemon формирует отчёт и определяет содержание записей и исходные оценки.
- Алгоритм автоматически рассчитывает среднее значение месяца, строит календарь и отображает недельные и категориальные показатели.
- Неделя без записи учитывается как 0 только в показателе зарегистрированной активности. Это не означает, что работа не велась.
- Знак «—» означает отсутствие данных, а не нулевой результат.
- Если отчёт охватывает несколько дней, календарь показывает этот период цветовым градиентом. Это не распределение работы по конкретным дням.
