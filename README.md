# Дневник работы

Личный рабочий дневник meme_lemon.

Основной сайт: https://memelemon.github.io/

## Архив
Записи хранятся в `data.json` внутри месяцев и годов. На странице доступны поиск по тексту, фильтр по году и фильтр по месяцу. Текст каждой записи выводится в исходной формулировке, без пересказа и редактирования.

## Показатели
- Календарь показывает период, охваченный отчётом, и дату его добавления.
- Категории и недельные показатели ведутся отдельно от текста записей.
- Неделя без отчёта не означает, что работа не велась.
- «—» означает, что данных пока нет.
